🌟 Viper Vision v1.12 Release Notes
Enterprise Stability & Testing:
• 
Bulletproof Spam Protection: The 30-second doorbell cooldown has been rigorously stress-tested. Rapid-fire doorbell presses (e.g., impatient delivery drivers or glitching motion sensors) are now guaranteed to be instantly absorbed without crashing the audio engine, spinning up duplicate video streams, or draining Gemini API tokens.
• 
100% Critical Path Test Coverage: Built a comprehensive, mocked testing suite (viper_test.py) to automatically verify API math, JSON parsing, garbage collection, and hardware routing without touching live APIs or physical speakers.
Fixes & Improvements:
• 
Thread-Safe UI Architecture: Eliminated the random "Not Responding" app freezes. Web commands (like remote Arm/Disarm) are now safely bridged to the Windows GUI using wx.CallAfter, perfectly separating the Flask server threads from the UI loop.
• 
System Tray Accessibility: Fixed an issue where restoring the app from the Windows system tray left screen readers silent. JAWS/NVDA will now instantly snap focus directly to the primary Arm/Disarm button upon waking.
• 
The "Space Ghost" Web Fix: The web interface now automatically strips invisible trailing spaces from speaker names and IP addresses during setup, preventing immediate Sonos handshake failures caused by mobile keyboard autocorrect.
• 
Instant Audio Memory Sync: Adding, toggling, or modifying a speaker via the web remote now triggers an immediate global memory sync. The background audio engine instantly recognizes the new hardware targets without requiring an app restart.
• 
Startup Sequence Optimization: Reordered the boot sequence to initialize the main dashboard before the web server starts listening. This completely eliminates random "Internal Server Error" flashes if the remote is accessed the exact second the PC boots up.
