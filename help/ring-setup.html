Do You Need Mosquitto Or ring-mqtt?

Viper itself does not require Mosquitto or ring-mqtt. Viper v1.2 can listen directly to Home Assistant state changes.

You may still need Mosquitto and ring-mqtt if Home Assistant does not already expose Ring motion, ding, or RTSP livestream entities.

Decision Guide

  • If Viper finds Ring motion or doorbell entities and your RTSP test passes, you do not need MQTT setup.
  • If Viper finds Ring entities but RTSP fails, set up go2rtc or ring-mqtt video streaming.
  • If Viper finds no Ring trigger entities, install Ring integration first. If that is not enough, install Mosquitto and ring-mqtt.
  • If you already use ring-mqtt, Viper can use the discovered Home Assistant entities or MQTT topics.

Install Mosquitto Broker In Home Assistant

  1. Open Home Assistant.
  2. Go to Settings, Add-ons, Add-on Store.
  3. Find Mosquitto Broker and install it.
  4. Turn on Start on boot and Watchdog.
  5. Create a Home Assistant user for MQTT, or use the credentials recommended by the Mosquitto add-on documentation.
  6. Start Mosquitto Broker.
  7. Confirm the MQTT integration is configured under Settings, Devices & services.

Install ring-mqtt

  1. Open Settings, Add-ons, Add-on Store.
  2. Open the three-dot menu and choose Repositories.
  3. Add the ring-mqtt Home Assistant add-on repository: https://github.com/tsightler/ring-mqtt-ha-addon.
  4. Install Ring-MQTT with Video Streaming.
  5. Enter your MQTT broker host, port, username, and password.
  6. Sign in to Ring using the add-on instructions.
  7. Enable livestream or RTSP support if you need Viper doorbell vision.
  8. Start the add-on and check its log for errors.

RTSP URL Pattern

Many Ring/go2rtc setups expose streams like this:

rtsp://YOUR_HA_IP:8554/YOUR_CAMERA_ID_live

In Viper, paste that URL into the front or back RTSP box and press the matching RTSP test button.

Use Viper's Ring Setup Assistant

  1. Open Utilities, Home Assistant Setup.
  2. Press Test & Discover.
  3. Press Ring Setup Assistant.
  4. Read the status box. It tells you whether you need trigger entities, RTSP, Mosquitto, or ring-mqtt.
