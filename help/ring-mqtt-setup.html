Mosquitto And Ring-MQTT Step By Step

Back to help index

What This Page Is For

Use this page if Viper needs Ring live video. Mosquitto and Ring-MQTT are the path Viper supports for Ring RTSP streams.

What The Pieces Mean

  • Mosquitto: the message broker inside Home Assistant.
  • Ring-MQTT with Video Streaming: signs in to Ring and exposes Ring camera streams.
  • RTSP: the live video URL Viper uses for Gemini vision.

Recommended Viper Path

  1. Open the Viper setup wizard.
  2. Go to Ring-MQTT Live Video.
  3. Press the button to install Ring-MQTT requirements.
  4. If Viper says Mosquitto or Ring-MQTT is already installed, that is fine. Viper should move to the login guide.
  5. Viper configures Ring-MQTT port 8554 when Home Assistant allows it.
  6. Viper opens the Ring-MQTT app page in your normal browser.

Important Browser Step

The Ring-MQTT login page usually does not open directly. Viper opens the Ring-MQTT app page first.

  1. If Home Assistant asks you to log in, log in to Home Assistant.
  2. If you land on the wrong Home Assistant page after login, return to Viper and press Open Ring-MQTT App Page In Browser again.
  3. On the Ring-MQTT app page, tab to Open Web UI.
  4. Press Open Web UI.
  5. The Ring-MQTT web page opens.
  6. Sign in to Ring there.

If You Must Install Manually

  1. Open Home Assistant.
  2. Go to Settings, Apps. Older versions may call this Add-ons or Add-on Store.
  3. Install Mosquitto Broker.
  4. Turn on Start on boot and Watchdog for Mosquitto.
  5. Start Mosquitto.
  6. Add the Ring-MQTT repository: https://github.com/tsightler/ring-mqtt-ha-addon
  7. Install Ring-MQTT with Video Streaming.
  8. Turn on Start on boot and Watchdog for Ring-MQTT.
  9. Make sure Ring-MQTT network port 8554/tcp maps to host port 8554.
  10. Start Ring-MQTT.
  11. Open its Web UI and sign in to Ring.

MQTT Username And Password

Some setups use Home Assistant's built-in authentication for Mosquitto. Other setups use a dedicated MQTT user. If Viper asks for MQTT credentials, enter the same MQTT host, port, username, and password Ring-MQTT uses.

For most Home Assistant OS setups, MQTT host is the Home Assistant IP and port is 1883.

Finding Streams

  1. Make sure Ring-MQTT is running and logged in to Ring.
  2. Return to Viper.
  3. Press Find Ring MQTT Streams or Find And Test Doorbell Cameras.
  4. Viper reads Ring-MQTT logs, Home Assistant attributes, and MQTT topics.
  5. Viper shows only streams it can turn into real RTSP URLs.
  6. Choose which stream belongs to each door and test it.

Console Fallback For Screen Reader Problems

If the Home Assistant Apps page cannot be used with your screen reader, use the Home Assistant VM console. At the ha > prompt, these are the basic commands:

addons repositories add https://github.com/tsightler/ring-mqtt-ha-addon
addons reload
addons install core_mosquitto
addons list

After addons list, find the Ring-MQTT slug and install it with addons install SLUG_HERE. If you are using Terminal or SSH instead of the VM console, put ha before each command.

What Viper Never Stores

  • Ring email.
  • Ring password.
  • Ring two-factor code.
  • Ring refresh token.

If Viper Finds No Streams

  • Confirm Ring-MQTT is logged in to Ring.
  • Confirm Ring-MQTT with Video Streaming is installed, not the non-video version.
  • Confirm port 8554 is exposed in the Ring-MQTT app configuration.
  • Restart Ring-MQTT after changing the port.
  • Press a Ring doorbell or trigger motion, then try stream discovery again.
  • Open Diagnostics and create a support bundle if it still fails.
