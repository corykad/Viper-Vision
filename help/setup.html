First Setup: The Whole Process

Back to help index

Recommended: Follow The Setup Wizard

On first run, Viper opens the setup wizard. Later, open the Home Assistant tab and press Open Setup Wizard.

The wizard is the beginner path. It keeps setup in one place. The Continue button for the next page only appears after the current step is ready.

Step 1: Home Assistant

  1. Press Check This PC And Home Assistant.
  2. If Home Assistant is found, Viper fills the address.
  3. If Home Assistant is not found and you do not have it installed, use Install VirtualBox, optionally Optimize Windows For VirtualBox, then Install Home Assistant.
  4. If Viper installs Home Assistant, choose RAM and disk space. The recommended choices are 4096 MB RAM and 32 GB disk.
  5. Review the install summary. It tells you what Viper will create and warns if Windows virtualization settings may cause trouble.
  6. Wait while Viper downloads, creates, starts, and watches Home Assistant. First boot can take up to 25 minutes.
  7. Press Open Home Assistant Account Setup.
  8. In the browser, create your Home Assistant owner account.
  9. Open your Home Assistant profile, create a long-lived access token named Viper Vision, and copy it.
  10. Return to Viper, paste the token, and press Connect And Discover Devices.

Step 2: Ring In Home Assistant

This step gives Viper doorbell trigger entities, such as ding, motion, or person detected.

  1. Open Home Assistant in the browser.
  2. Go to Settings, Devices and services.
  3. Add or open the Ring integration.
  4. Sign in to Ring when Home Assistant asks.
  5. Return to Viper and check for Ring doorbell triggers.

This is separate from Ring-MQTT. The normal Ring integration in Home Assistant provides these trigger entities. Ring-MQTT is for live video.

Step 3: Ring-MQTT Live Video

Doorbell AI needs live video. Ring snapshots can be stale, so Viper uses Ring-MQTT RTSP streams.

  1. In the wizard, use the Ring-MQTT Live Video step.
  2. Let Viper install or detect Mosquitto and Ring-MQTT with Video Streaming.
  3. Open the Ring-MQTT app page in your normal browser.
  4. If Home Assistant asks you to sign in, sign in.
  5. On the Ring-MQTT app page, use Open Web UI.
  6. Sign in to Ring inside Ring-MQTT.
  7. Return to Viper and press the button to find Ring-MQTT streams.

Step 4: Test Doorbell Cameras

  1. Press Find And Test Doorbell Cameras.
  2. Viper reads Ring-MQTT logs, attributes, and topics. It does not guess URLs from camera entity names.
  3. Choose the stream for each door you use.
  4. Press Save Selected Camera Streams.
  5. Press Test Front Doorbell Camera and Test Back Doorbell Camera.
  6. If you only have one doorbell, configure and test only that door.

Step 5: Confirm Doorbell Triggers

  1. Review the front and back trigger combo boxes.
  2. Choose the entity that changes when the doorbell rings or motion is detected.
  3. Press Save Selected Doorbell Triggers.
  4. If Viper chose wrong, change the combo box and save again.

Step 6: Choose Speakers

  1. Press the speaker discovery button.
  2. Tab through the speaker checkboxes.
  3. Press Space to check only the speakers Viper should use.
  4. Choose whether those speakers receive doorbell, utility, fridge/freezer, and quiet-hours alerts.
  5. Press Save Selected Speakers.
  6. Press Test Checked Speakers.

Step 7: AI And Speech

  1. Enter or confirm the Gemini API key.
  2. Choose default TTS behavior.
  3. Leave Gemini warmup off unless you accept possible API charges for warmup requests.
  4. Keep doorbell speech fast and utility speech normal unless you prefer otherwise.

Step 8: Final Test

  1. Press Test Everything.
  2. Read the status box.
  3. Fix anything marked Needs setup.
  4. When the core doorbell flow passes, finish setup.

Optional Devices

Refrigerator, freezer, ice maker, and robot vacuum setup can wait. After the main doorbell system works, use Set Up Refrigerator Alerts, Set Up Robot Vacuum, or open Home Devices.

Optional: Alexa And Google Controls

After Home Assistant and speakers are saved, open the Home Assistant tab and press Set Up Alexa And Google Controls. Viper checks Home Assistant, installs or starts Samba and Matterbridge when Home Assistant allows it, creates switch entities for Viper Armed, Global Mute, Ice Maker, and your saved speakers, can add real Home Assistant fan entities, and configures Matterbridge.

The Matter pairing code is unique to each Matterbridge install. Viper does not guess it. Open Matterbridge and use the QR code or manual setup code shown there when adding a Matter device in Alexa or Google Home.

Advanced YAML Export

Most new users should ignore YAML export. It is for users who prefer Home Assistant-side automations. Viper's direct Home Assistant listener is the normal beginner path.
