Create A Home Assistant Token

  1. In Home Assistant, open your user profile.
  2. Find Long-Lived Access Tokens.
  3. Create a token named Viper Vision.
  4. Copy it immediately. Home Assistant only shows it once.

Connect Viper

  1. In Viper, open Utilities, then Home Assistant Setup.
  2. Press Find HA. If this fails, type the host manually.
  3. Paste the Home Assistant token.
  4. Paste your Gemini API key.
  5. Leave Direct Home Assistant listener enabled.
  6. Press Test & Discover.

Choose Doorbell Triggers

A trigger entity is the Home Assistant entity that changes when something happens. For a doorbell, this might be motion, ding, person detected, or button pressed.

Choose one trigger entity for the front door and one for the back door. If you only use one door, configure only that door.

Test RTSP

Doorbell AI needs a live RTSP stream. Home Assistant snapshots may be old, so Viper does not use snapshots as the default doorbell source.

Press Test Front RTSP and Test Back RTSP. Save only after the streams work.

Advanced YAML Export

The Advanced: Export HA YAML Package button is for users who prefer Home Assistant automations. It is optional in v1.2.

Optional Remote Web Access

After local setup works, you can use Tailscale to open Viper's remote web page from your phone or another computer without exposing Viper to the public internet. See Remote Web Access With Tailscale.
