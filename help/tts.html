Default TTS Settings

The default TTS engine applies to all alerts unless a category override is enabled.

Per-Alert Settings

Doorbell alerts, utility alerts, and manual broadcasts can use the default voice or their own engine, voice, speed, and dynamic mood setting.

Gemini TTS Warmup

Gemini warmup can reduce first-alert delay, but it sends API requests and may be billed. Leave it off unless you accept that tradeoff.

Speed Choices

Use faster speeds for doorbell alerts and normal or brisk speeds for utility messages. If speech becomes hard to understand, lower the category speed.
