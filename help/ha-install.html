Installing Home Assistant For Viper Vision

Back to help index

Best Beginner Choice

The smoothest long-term setup is usually a dedicated Home Assistant device, such as Home Assistant Green, Home Assistant Yellow, or a small mini PC. It keeps your smart home running even when your Windows computer restarts.

Trying Home Assistant On This Windows PC

For testing or a budget setup, use Home Assistant OS in VirtualBox. Viper does not bundle or silently install VirtualBox because that creates admin, licensing, antivirus, and machine-specific VM problems.

What The Viper Assistant Can Do

  • Check whether VirtualBox is installed.
  • Open the official VirtualBox download page.
  • Open the official Home Assistant Windows installation guide.
  • Open the official Home Assistant OS release download page.
  • Look for Home Assistant on your network.
  • Hand off to Viper's Home Assistant setup once HA is reachable.

Windows VirtualBox Setup

  1. Open Viper, Utilities, New User Setup Assistant.
  2. Press Open HA Windows Guide.
  3. Press Open VirtualBox Download and install VirtualBox from Oracle.
  4. Press Open HA OS Download and download the VirtualBox image listed by Home Assistant.
  5. Follow the official Home Assistant Windows guide to create or import the VM.
  6. Start the VM.
  7. Wait for Home Assistant to finish first boot. This can take several minutes.
  8. Open http://homeassistant.local:8123 in a browser.
  9. Complete Home Assistant onboarding and create your owner account.
  10. In Home Assistant, open your user profile and create a long-lived access token.
  11. Return to Viper and press Find Home Assistant.
  12. Press Continue To Viper Setup.

Network Notes

If Viper cannot find Home Assistant, try entering the Home Assistant IP manually. The VM must be reachable from Windows. If VirtualBox networking is set in a way that isolates the VM, Home Assistant may work in the VM but not be visible to Viper.

What Not To Install Unless Needed

You do not need Samba, File Editor, Mosquitto, or ring-mqtt just to connect Viper to Home Assistant. Mosquitto and ring-mqtt are only needed for certain Ring setups. See the Ring setup help page.
