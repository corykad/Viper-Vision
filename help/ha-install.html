Installing Home Assistant If You Do Not Have It

Back to help index

Best Choice For Most Homes

The most reliable Home Assistant setup is a dedicated device, such as Home Assistant Green or a small mini PC. It keeps running when the Windows computer restarts.

If you want to try Home Assistant on the same Windows computer as Viper, Viper can install Home Assistant OS in VirtualBox.

What Viper Can Install

  • Oracle VirtualBox, using winget.
  • The official Home Assistant OS VirtualBox image.
  • A VirtualBox VM named Home Assistant.

Viper does not bundle Home Assistant or VirtualBox inside the Viper installer. It downloads from official sources when you choose the install step.

Before You Start

  • This automatic installer is for Windows x64 computers.
  • Windows ARM, Raspberry Pi, Mac, and other ARM devices need a different Home Assistant install method.
  • VirtualBox may be less stable if Hyper-V, Windows Hypervisor Platform, Virtual Machine Platform, WSL2, Docker Desktop, or Windows Sandbox are active.
  • Viper offers an optional Optimize Windows For VirtualBox button. It warns first, requires administrator permission, and requires a reboot.

Step By Step

  1. Open Viper's setup wizard.
  2. Go to the Home Assistant step.
  3. Press Check This PC And Home Assistant.
  4. If VirtualBox is missing, press Install VirtualBox.
  5. If Viper reports Windows hypervisor features may cause VirtualBox problems, press Optimize Windows For VirtualBox only if you accept the tradeoff. This can affect WSL2 and Docker Desktop until those Windows features are re-enabled.
  6. If you used Optimize Windows For VirtualBox, reboot Windows before continuing.
  7. Press Install Home Assistant.
  8. Choose RAM and disk space. Recommended: 4096 MB RAM and 32 GB disk.
  9. Read the review summary. It shows selected RAM, disk, install folder, drive-space status, and the expected first-boot wait.
  10. Choose Yes to continue.
  11. Wait while Viper downloads Home Assistant OS, creates the VM, starts it, and checks readiness.
  12. When Viper says Home Assistant is ready, press Open Home Assistant Account Setup.
  13. Create your Home Assistant owner account in the browser.
  14. Create a long-lived access token and return to Viper.

Choosing RAM

  • 2048 MB: minimum, for testing or very small computers.
  • 4096 MB: recommended for most users.
  • 6144 MB or 8192 MB: useful if the PC has enough RAM and Home Assistant will run many integrations or add-ons.

Choosing Disk Space

  • 16 GB: minimum testing size.
  • 32 GB: recommended for most users.
  • 64 GB or more: better if you expect lots of add-ons, logs, recorder history, or camera-related tools.

Why First Boot Takes So Long

After the VM starts, Home Assistant may still download and prepare Home Assistant Core. The browser can show a high percentage for a long time. Viper waits up to 25 minutes and keeps reporting progress.

Home Assistant IP Address

Viper uses bridged networking when VirtualBox exposes a bridged adapter. That usually gives Home Assistant its own local IP address.

Viper cannot reserve an IP inside every router, because routers all work differently. Instead, Viper keeps checking the saved Home Assistant address while it runs. If the old address stops responding and Home Assistant is found at a new local IP, Viper updates the saved address.

Manual Download Fallback

  1. Press Open HA OS Download.
  2. Download the VirtualBox image from the Home Assistant OS releases page.
  3. Return to Viper and press Choose Downloaded HA OS Image.
  4. Choose the downloaded zip, VDI, or OVA file.
  5. Choose RAM and disk space.
  6. Review the summary and continue.

What Viper Does Not Do

  • Viper does not create your Home Assistant owner account.
  • Viper does not store your Home Assistant password.
  • Viper does not bypass Home Assistant onboarding.
  • Viper does not change Windows virtualization settings without asking first.
