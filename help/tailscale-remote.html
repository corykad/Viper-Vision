Remote Web Access With Tailscale

Back to help index

What This Is For

Viper has a local remote web page for broadcasts, speaker controls, Cinderella messages, and quick status checks. Tailscale lets you open that page from your own phone or laptop when you are away from home, without opening a router port to the public internet.

Recommended Security Choice

Use normal Tailscale private access. Do not use Tailscale Funnel for Viper unless you intentionally want to publish the Viper web page outside your private tailnet.

Install Tailscale On The Viper Computer

  1. On the Windows computer running Viper, open the official Tailscale Windows install page.
  2. Install Tailscale.
  3. Sign in to Tailscale.
  4. Confirm the computer appears in your Tailscale admin console or Tailscale app.
  5. Leave Viper running.

Install Tailscale On The Remote Device

  1. Install Tailscale on the phone, tablet, or laptop you want to use remotely.
  2. Sign in with the same Tailscale account, or accept a machine sharing invitation from the Viper computer's tailnet.
  3. Confirm the remote device shows as connected.

Find The Viper Computer's Tailscale Address

On the Viper computer, open the Tailscale app and find its Tailscale IP address. It usually starts with 100.. You can also use the machine name if MagicDNS is enabled.

Open The Remote Page

From the remote device, open one of these addresses:

http://TAILSCALE_IP:5050/remote
http://MACHINE-NAME:5050/remote

Replace TAILSCALE_IP with the Viper computer's Tailscale IP. Replace MACHINE-NAME with the Viper computer's Tailscale name if MagicDNS works in your tailnet.

Test Checklist

  1. Open Viper locally on the Windows computer.
  2. Open http://127.0.0.1:5050/remote on the Viper computer.
  3. If local access works, open http://TAILSCALE_IP:5050/remote from the remote device.
  4. Send a short manual broadcast.
  5. Check that the expected speaker or chime responds.

If It Does Not Open

  • Make sure Viper is running.
  • Make sure both devices are connected in Tailscale.
  • Try the Tailscale IP instead of the machine name.
  • Try the local page on the Viper computer: http://127.0.0.1:5050/remote.
  • Check Windows Firewall. Allow Python or Viper Vision to accept private network connections.
  • Do not use https unless you have separately configured a proxy or Tailscale Serve. Viper's built-in web server uses http.

Sharing With Another Person

If another person needs access, share only the Viper computer through Tailscale. Tailscale machine sharing gives the other person access to the shared computer, not your whole tailnet.

Funnel And Serve

Tailscale Serve can publish a local service inside your private tailnet. Tailscale Funnel can publish a service to the public internet. For Viper, private tailnet access is the safer default. Use Funnel only if you understand the exposure and have a separate access-control plan.
