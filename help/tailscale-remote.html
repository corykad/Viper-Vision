Remote Web Access With Tailscale

Back to help index

What This Is

Viper has a remote web page for broadcasts, speaker controls, robot messages, and quick checks. Tailscale lets your own phone or laptop open that page without exposing Viper to the public internet.

Do This After Local Setup Works

Set up doorbells and speakers locally first. Add Tailscale after Viper works on the home network.

Step By Step

  1. Install Tailscale on the Windows computer running Viper.
  2. Sign in to Tailscale.
  3. Install Tailscale on your phone, tablet, or remote computer.
  4. Sign in with the same Tailscale account, or share the Viper computer to that user.
  5. On the Viper computer, open http://127.0.0.1:5050/remote. Confirm it works locally.
  6. Find the Viper computer's Tailscale IP. It usually starts with 100..
  7. On the remote device, open http://TAILSCALE_IP:5050/remote.

Security Recommendation

Use normal private Tailscale access. Do not use Tailscale Funnel for Viper unless you understand that Funnel can expose a service outside your private tailnet.

If It Does Not Open

  • Make sure Viper is running.
  • Make sure both devices show connected in Tailscale.
  • Try the Tailscale IP instead of the computer name.
  • Check Windows Firewall and allow Viper or Python on private networks.
  • Use http, not https, unless you configured a proxy separately.
