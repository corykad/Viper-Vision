Choosing Speakers And Chimes

Back to help index

During First Setup

  1. Go to the Speakers and Audio step in the wizard.
  2. Press the discovery button.
  3. Tab through the speaker checkboxes.
  4. Press Space to check each speaker Viper should use.
  5. Leave speakers unchecked if you do not want Viper to use them.
  6. Choose the routes for the checked speakers.
  7. Press Save Selected Speakers.
  8. Press Test Checked Speakers.

Speaker Types

  • Home Assistant media player entities.
  • Sonos speakers by IP address.
  • Alexa media player entities, if your Home Assistant setup supports them.

Routes

Routes decide what each speaker is allowed to play.

  • Doorbell: doorbell chimes and doorbell AI speech.
  • Utilities: general house alerts and status messages.
  • Fridge/freezer: refrigerator and freezer chimes or announcements.
  • Quiet-hours exempt: allows urgent alerts on that speaker even during quiet hours.

Chime-Only Alerts

Fridge and freezer channels can be set to speak, chime, or silent. If a channel is set to chime, Viper should play only the chime and should not generate TTS.

If You Hear Nothing

  1. Make sure at least one speaker is checked and saved.
  2. Run Test Checked Speakers.
  3. Confirm the speaker is powered on and reachable from Home Assistant or the network.
  4. Open Diagnostics and run speaker tests.
