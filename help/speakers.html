Speaker Types

  • Home Assistant media player entity.
  • Sonos speaker IP address.
  • Alexa media player entity if your Home Assistant setup supports it.

Routing

Each speaker can receive doorbell, utility, fridge/freezer, and quiet-hours-exempt alerts. Select a speaker, then choose its routing checkboxes.

Chimes

Front and back doors can use different chimes. Fridge and freezer channels can speak, chime, or stay silent.
