The Short Version

Viper Vision watches Home Assistant for events, grabs a live camera frame when a doorbell rings, asks Gemini what is happening, and plays chimes or speech on the speakers you choose.

What You Need Before Viper Is Fully Working

  • Home Assistant running on your network.
  • A Home Assistant long-lived access token.
  • A Gemini API key for AI vision and Gemini voices.
  • At least one speaker selected in Viper.
  • For Ring doorbells: Ring trigger entities in Home Assistant and Ring-MQTT live RTSP streams.

Recommended Setup Order

  1. Open Viper Vision.
  2. Use the setup wizard. Do not start in Advanced unless support asks you to.
  3. Connect to Home Assistant, or install Home Assistant if you do not have it.
  4. Create your Home Assistant account in the browser.
  5. Create and paste a long-lived access token.
  6. Let Viper discover devices.
  7. Sign in to Ring inside Home Assistant so doorbell trigger entities appear.
  8. Install Mosquitto and Ring-MQTT so Viper can get live Ring video.
  9. Let Viper find and test Ring-MQTT camera streams.
  10. Choose and test speakers.
  11. Optional: set up Alexa and Google controls after the core setup works.
  12. Run Final Test.

What Success Looks Like

  • The Home Assistant checklist says the address, token, and live connection passed.
  • Doorbell trigger entities are selected for the doors you use.
  • Front and back camera tests say passed, or only the door you use says passed.
  • At least one speaker is checked and saved.
  • Test Everything finishes without a critical error.

Where Things Are In Viper

  • Dashboard: arm or disarm Viper and see recent status.
  • Doorbell Vision: doorbell tests, camera status, chimes, and AI description settings.
  • Speakers and Audio: speakers, routing, quiet hours, and TTS voices.
  • Home Devices: refrigerator, freezer, ice maker, and robot vacuum controls.
  • Home Assistant: the setup wizard and setup checklist.
  • Diagnostics: tests, logs, support bundle, and speed checks.
  • Advanced: manual tools for users who know they need them.

Important Beginner Rule

When in doubt, stay in the setup wizard. The wizard is designed to show the next button only after the current step is ready.
