What Viper Needs

  • Home Assistant host, usually homeassistant.local or an IP address.
  • A Home Assistant long-lived access token.
  • A Gemini API key for doorbell AI and Gemini speech.
  • At least one speaker target.
  • For doorbell AI, a Home Assistant trigger entity and a live RTSP URL.

Recommended v1.2 Setup

  1. Open Viper Vision.
  2. Open Utilities, then Home Assistant Setup.
  3. Press Find HA.
  4. Paste your Home Assistant long-lived access token and Gemini API key.
  5. Press Test & Discover.
  6. Choose front and back doorbell trigger entities.
  7. Enter or derive live RTSP URLs.
  8. Press Test Front RTSP and Test Back RTSP.
  9. Press Save.

Important Change In v1.2

Viper can listen directly to Home Assistant state changes. New users do not need to edit Home Assistant YAML, install Samba, or copy package files just to get doorbell alerts working.

Remote Web Access

For access away from home, use Tailscale on the Viper computer and on your phone or laptop. See Remote Web Access With Tailscale.
