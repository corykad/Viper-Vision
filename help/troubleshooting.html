Troubleshooting And Speed

Home Assistant Not Found

Try entering homeassistant.local, the Home Assistant IP address, and port 8123. Confirm the Windows PC and Home Assistant are on the same network.

Token Rejected

Create a new long-lived access token from your Home Assistant user profile and paste it into Viper.

No Trigger Entities

Install or fix the relevant Home Assistant integration. For Ring, try the Ring integration first, then Mosquitto and ring-mqtt if needed.

RTSP Test Fails

Confirm the URL opens in another RTSP client, confirm go2rtc or ring-mqtt is running, and confirm Viper's bundled FFmpeg is present in the installed app.

Doorbell Speech Is Slow

Open the Speed tab and press Refresh speed diagnostics. Compare RTSP capture, Gemini vision, Gemini TTS, and speaker playback times.

Remote Web Page Does Not Open Over Tailscale

Confirm Tailscale is running and signed in on both devices. On the remote device, open Viper using the Viper computer's Tailscale IP and port 5050. Example: http://100.x.y.z:5050/remote. If it works at home but not over Tailscale, check Windows Firewall and make sure Viper is running.

Gemini Warmup Costs

Gemini warmup sends requests to the API. Those requests may count as billable API usage. Leave warmup off unless you want the lowest first-alert latency and accept possible cost.

Logs

Installed builds store logs under %APPDATA%\viper_vision_1.0. Source runs store logs in the project folder.
