Troubleshooting And Speed

Start With Diagnostics

  1. Open Diagnostics in Viper.
  2. Run Diagnostics.
  3. Read the status box from top to bottom.
  4. If you need help, create a support bundle. Viper redacts secrets before zipping logs.

Home Assistant Is Not Found

  1. Open Home Assistant in your browser if you know the address.
  2. If it opens, copy the IP or host into Viper.
  3. Make sure the port is 8123.
  4. Create a fresh long-lived token and paste it into Viper.
  5. Press Connect And Discover Devices.

Home Assistant VM Runs But The Web Page Hangs

Try both addresses:

http://YOUR_HOME_ASSISTANT_IP:8123
http://YOUR_HOME_ASSISTANT_IP:4357

If 4357 opens but 8123 hangs, the VM is alive and Home Assistant Core is likely stuck. Run diagnostics and check Home Assistant logs.

Token Rejected

Create a new long-lived token from the same Home Assistant account you use in the browser. Paste the new token into Viper and try discovery again.

No Ring Trigger Entities

Fix the Home Assistant Ring integration first. Ring-MQTT gives live video, but the normal Ring integration is often the easiest trigger source.

No Ring RTSP Streams

  1. Confirm Mosquitto is running.
  2. Confirm Ring-MQTT with Video Streaming is installed.
  3. Confirm Ring-MQTT is logged in to Ring.
  4. Confirm Ring-MQTT port 8554 is exposed.
  5. Restart Ring-MQTT after changing port settings.
  6. Press Find And Test Doorbell Cameras again.

No Sound

  1. Make sure at least one speaker is checked and saved.
  2. Run Test Checked Speakers.
  3. Check the route for that speaker: doorbell, utilities, fridge/freezer, or quiet-hours exemption.
  4. If fridge/freezer is set to chime, expect a chime, not speech.
  5. Open Diagnostics and run speaker tests.

Doorbell Speech Or AI Is Slow

  1. Open Diagnostics.
  2. Run speed diagnostics.
  3. Compare RTSP capture, Gemini vision, TTS generation, and speaker playback.
  4. If Gemini TTS is slow, use Edge TTS for doorbells and Gemini for less urgent messages.

Logs And Support Bundle

Open Diagnostics, Tests and Support, then About Viper Vision And Data Folders. That page shows the config file, log folder, support bundle folder, and local remote URL.
