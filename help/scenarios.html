Common Setup Scenarios

Back to help index

I Am Brand New

Start with First Setup. Do not use Advanced until the wizard tells you to or support asks you to.

I Do Not Have Home Assistant Yet

Use the Home Assistant step in the wizard. Viper can install Home Assistant OS in VirtualBox on Windows x64. See Installing Home Assistant If You Do Not Have It.

I Already Have Home Assistant

  1. Find the Home Assistant address.
  2. Create a long-lived token.
  3. Paste it into Viper.
  4. Press Connect And Discover Devices.

I Have One Doorbell

Configure only that door. It is okay to leave the other door unassigned.

I Have More Than Two Ring Cameras

Let Viper discover all Ring-MQTT streams, then choose which one belongs to the front door and which one belongs to the back door. Ignore the others.

I Do Not Want YAML

You do not need YAML for the beginner setup. Viper can listen directly to Home Assistant state changes.

I Still Use Old Home Assistant Automations

You can keep them. Viper still supports webhooks and advanced YAML export. New users should use the direct listener first.

I Want Refrigerator Or Freezer Alerts

Finish the main doorbell setup first. Then open Home Devices, Refrigerator and Ice. Choose chime, speak, or silent for the fridge and freezer channels.

I Want Roborock Controls

Install the Roborock integration in Home Assistant first. Then open Home Devices, Robot Vacuum, refresh controls and rooms, and test safe actions before cleaning selected rooms.
