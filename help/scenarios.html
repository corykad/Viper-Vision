Common Setup Scenarios

Back to help index

Fresh Home Assistant Install

Use the direct listener setup. You only need the Home Assistant token, Gemini API key, speaker entities, doorbell trigger entities, and RTSP URLs.

No Samba Or File Editor

You do not need Samba or File Editor for the beginner setup. Viper talks to Home Assistant over its API.

Only One Doorbell

Configure only the door you use. Leave the other trigger entity blank.

No RTSP Yet

Doorbell AI should wait until you have a live RTSP stream. Configure go2rtc, ring-mqtt video streaming, or another camera stream provider.

Using Existing YAML Automations

You can keep them. Existing webhook endpoints still work. The direct listener is the simpler default for new setups.

Home Assistant Speakers

Use Scan HA for Speakers, then select which speakers receive doorbell, utility, fridge, and quiet-hours-exempt alerts.

Fridge And Freezer Alerts

Viper can announce or chime for fridge and freezer open or closed events. The default entity IDs are listed in the HA Status tab.

Roborock Vacuum

Install the Home Assistant Roborock integration, then use the Vacuum tab to discover controls and rooms.

Gemini Speech Is Slower Than Push

This is expected sometimes. Pushover sends a small notification quickly. Gemini TTS has cloud generation latency. Use the Speed tab to compare RTSP, Gemini vision, Gemini TTS, and speaker dispatch timing.
