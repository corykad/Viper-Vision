Alexa And Google Controls

What This Does

Viper can expose controls to Alexa and Google Home through Home Assistant, Matterbridge, and Matter.

The controls are based on your current Viper setup. Every user gets their own Home Assistant address, speaker names, fan entities, and Matter pairing code.

Controls Viper Creates

  • Viper Armed: on means armed, off means disarmed.
  • Viper Global Mute: on means all Viper audio is muted, off means audio is allowed.
  • One switch for each saved Viper speaker.
  • Optional real Home Assistant fan entities that you add with Add Alexa Ceiling Fan.

Before You Start

  • Home Assistant must be connected in Viper.
  • A Home Assistant long-lived access token must be saved in Viper or available in environment variables.
  • Run speaker setup first if you want individual speaker switches.
  • Create or discover the ceiling fan in Home Assistant first if you want to expose a fan. Viper needs a real fan entity ID that starts with fan.
  • Home Assistant OS or Supervised is needed for Viper to install add-ons automatically.

Automatic Setup

  1. Open the Home Assistant tab in Viper.
  2. Press Set Up Alexa And Google Controls.
  3. If you are adding a fan, press Add Alexa Ceiling Fan and enter the Home Assistant fan entity ID.
  4. Read the report.
  5. If every line says OK, open Matterbridge from the link in the report.
  6. Add Matterbridge to Alexa or Google Home using the Matter code or QR code shown by Matterbridge.

What Viper Tries To Install

  • Samba share, so Viper can copy the Home Assistant package into the config folder.
  • Matterbridge, so Home Assistant controls can be exposed as Matter devices.
  • The matterbridge-hass plugin inside Matterbridge.

If Automatic Install Is Blocked

Some Home Assistant tokens can read normal Home Assistant entities but cannot manage add-ons. Home Assistant Core and Container installs do not have Supervisor add-ons. In those cases, Viper shows manual steps.

The manual path is: install Samba share if available, install Matterbridge, install matterbridge-hass, then run Set Up Alexa And Google Controls again.

Alexa Pairing

  1. In Alexa, add a device.
  2. Choose Matter.
  3. If Alexa asks whether the device has a Matter logo, choose Yes.
  4. If asked for device type, choose Generic Matter device.
  5. Use the Matterbridge manual code or QR code.

Google Home Pairing

  1. In Google Home, add a device.
  2. Choose Matter-enabled device.
  3. Use the Matterbridge QR code or manual setup code.

Troubleshooting

  • If Samba is missing, install the official Samba share add-on and confirm Windows can open \\HOME_ASSISTANT_IP\config.
  • If Viper cannot copy the package, check Samba, Windows credentials, and whether packages are enabled in configuration.yaml.
  • If Matterbridge is missing, install the Matterbridge add-on and start it.
  • If matterbridge-hass is missing, install it inside Matterbridge and run the setup again.
  • If speaker switches are missing, run speaker setup in Viper and then run this setup again.
  • If a fan is missing, confirm it exists in Home Assistant as a fan entity, then add it again in Viper.
  • If Alexa or Google does not show new controls, restart Matterbridge and rediscover Matter devices.
