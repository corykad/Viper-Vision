Before You Use This

  1. Add the Roborock integration in Home Assistant.
  2. Let Viper discover Home Assistant devices.
  3. Open Home Devices, Robot Vacuum.

Safe First Tests

  1. Press refresh or discover controls.
  2. Try Locate first. That confirms Viper can reach the vacuum without starting a cleaning job.
  3. Try Return to dock if the robot is away from the dock.

Cleaning Controls

Viper shows only the basic actions that make sense for the vacuum's current state. Pause and Stop appear while the robot is cleaning or paused. Start appears when the robot is docked, idle, or paused. Return to dock appears when it is useful.

The Cleaning job mode picker tells Viper whether the next whole-home clean or selected-room clean should be Vacuum and mop, Vacuum only, or Mop only. When Home Assistant exposes a matching Roborock cleaning-mode or mop-mode control, Viper applies that setting before it starts the job. If Home Assistant does not expose a matching control, the robot uses its current Roborock app settings.

The Start selected cleaning mode button starts or resumes the selected vacuum. It does not choose suction or mop intensity by itself; use the suction, mop mode, and mop intensity controls first if you want exact values.

Room Cleaning

  1. Choose the vacuum entity.
  2. Choose Cleaning job mode: Vacuum and mop, Vacuum only, or Mop only.
  3. Press Refresh room list.
  4. Tab or arrow through the rooms.
  5. Press Space to check or uncheck each room.
  6. Choose repeat count.
  7. Press Clean selected rooms.

Viper saves discovered room IDs. If you remap the house in Roborock, refresh rooms again.

Cinderella Messages

Cinderella messages are the funny robot vacuum status messages. You can edit message buckets for departure, washing, emptying, drying, returning, victory, paused, status updates, vacuum errors, dock errors, and specific errors.

If A Control Is Missing

Viper can only use controls Home Assistant exposes. If a suction or mop option is missing, check the Roborock integration in Home Assistant first.
